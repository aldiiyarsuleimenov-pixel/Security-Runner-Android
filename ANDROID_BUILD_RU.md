# Security Runner — Android APK (без Replit)

Проект собирает самостоятельный Android APK. Игра будет храниться внутри приложения и открываться без сайта и без Replit.

## Сборка через GitHub Actions с телефона

1. На GitHub создай новый пустой репозиторий, например `security-runner-android`.
2. Распакуй этот ZIP на телефоне.
3. Загрузи **содержимое папки `2D-Action-Platformer`** в корень репозитория GitHub (не загружай сам ZIP как единственный файл).
4. Открой вкладку **Actions** в репозитории.
5. Выбери workflow **Build Security Runner APK**.
6. Нажми **Run workflow** → ещё раз **Run workflow**.
7. Дождись зелёной галочки у запуска, открой его и найди блок **Artifacts**.
8. Скачай `Security-Runner-APK.zip`, распакуй его и установи `app-debug.apk` на Android.

Также workflow автоматически запускается при каждом push в ветку `main`.

## Примечания

- APK собирается в debug-режиме для личного тестирования. Для публикации в Google Play нужна отдельная release-подпись.
- Игра работает локально внутри APK. Интернет нужен только для загрузки VCR OSD Mono, так как текущая таблица стилей подключает этот шрифт с CDN.
- В исходной игре пока не было аудиодорожек; регуляторы громкости интерфейса сохраняют уровни, но начнут реально управлять звуком после добавления треков и эффектов.
